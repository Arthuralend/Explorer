# Проводник для Android

Двухпанельный файловый менеджер в духе классического Проводника Windows — с современным дизайном в цветах Claude (терракота, кремовый, графит), светлой и тёмной темой.

## Возможности

- **Две панели** — сверху/снизу в портретной ориентации, слева/справа в альбомной. Активная панель подсвечена.
- **Навигация как в Windows**: кнопки «Назад», «Вперёд», «Вверх», адресная строка-«хлебные крошки» (`Этот компьютер › Внутренняя память (C:) › Download`).
- **«Этот компьютер»**: папки (Загрузки, Документы, Изображения, Камера, Музыка, Видео) и диски с полосой заполнения — внутренняя память `C:`, SD-карта `D:` и т. д.
- **Открытие как в классическом Windows**: одно нажатие выделяет, двойное — открывает, долгое — контекстное меню (аналог правой кнопки). В меню «Ещё» можно включить открытие одним нажатием.
- **Виды**: «Таблица» (на широкой панели — колонки Имя / Дата изменения / Тип / Размер с сортировкой по нажатию на заголовок) и «Крупные значки» с миниатюрами картинок.
- **Иконки в стиле Windows 11**: жёлтые папки, значки для особых папок, листы с цветной меткой расширения, диски и SD-карта.
- **Операции**: новая папка, вырезать/копировать/вставить, копировать и переместить в соседнюю панель, переименовать, удалить, поделиться, свойства (размер папки, число файлов). При конфликте имён — «Имя - копия», как в Windows.
- Скрытые файлы, множественное выделение, «Выделить всё», поменять панели местами, открыть ту же папку в другой панели.

## Установка

Каждый пуш в `main` собирает APK через GitHub Actions. Готовый файл — в релизе **latest**:
`Releases → latest → Explorer.apk`. При первом запуске приложение попросит доступ ко всем файлам.

Сборки подписаны одним и тем же ключом из `keystore/` (только для самостоятельной установки, не секрет), поэтому новые версии ставятся поверх старых.

## Сборка вручную

```bash
./gradlew assembleRelease
```

Требуется JDK 17 и Android SDK (compileSdk 35). Минимальная версия Android — 8.0.
